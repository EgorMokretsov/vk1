Разработан и проверен инструмент на C# для автоматического запуска двух проходов Black Myth: Wukong Benchmark Tool через Steam, применения настроек, распознавания FPS и формирования отчёта с характеристиками ПК.

Ссылка на решение: https://github.com/EgorMokretsov/vk1

Репозиторий публичный, доступ открыт без приглашений. Инструкция находится в README.md, результаты проверенного запуска — в папке results.

Краткая инструкция по запуску:
1. Использовать Windows 10/11 x64, установить .NET 8 SDK и Black Myth: Wukong Benchmark Tool в Steam, войти в Steam.
2. Один раз открыть Benchmark Tool, пройти начальную подготовку, выбрать English и закрыть приложение. Установить компонент English (United States) OCR в параметрах языка Windows.
3. Скачать репозиторий через Code → Download ZIP, распаковать и открыть PowerShell в папке проекта.
4. Выполнить: .\run.cmd --gpu-resolution 1280x720 --no-ray-tracing --open-report
5. Оставить рабочий стол разблокированным и не пользоваться мышью и клавиатурой до завершения. Программа сама выполнит оба прохода, восстановит исходные настройки и откроет HTML-отчёт. Отчёт и подтверждающие файлы сохраняются в results/<дата-время>.

Выбор настроек:
CPU-проход: 1280×720, масштаб рендера 50%, TSR; большинство параметров качества — Low, дальность прорисовки и растительность — Cinematic. Низкое разрешение и качество эффектов уменьшают нагрузку на GPU, а высокая дальность и растительность сохраняют работу CPU по обработке объектов и подготовке команд отрисовки. RT, генерация кадров, VSync и ограничение FPS выключены. Этот профиль уменьшает влияние GPU, но не гарантирует, что на любой видеокарте результат будет ограничен исключительно процессором.

GPU-проход: 1280×720, масштаб рендера 100%, все группы качества — Cinematic, TSR; RT выключена, генерация кадров, VSync и ограничение FPS также выключены. Рендер в полном выбранном разрешении и максимальное качество увеличивают нагрузку на видеокарту. На проверенном ПК с встроенной AMD Radeon Graphics использован доступный режим без RT; ранее режим 1920×1080 завершался с GPUCrash. Поэтому для воспроизводимого запуска указан проверенный профиль 1280×720. Без параметра --gpu-resolution программа использует разрешение основного монитора; максимальная нагрузка определяется выбранным разрешением и поддерживаемыми функциями.

Подтверждённый результат полного автоматического запуска: CPU — средний 20 FPS, минимум 3, максимум 26; GPU — средний 1 FPS, минимум 0, максимум 2. Обе настройки проверены, значения FPS подтверждены повторными снимками, статус отчёта — completed, исходные настройки восстановлены.
